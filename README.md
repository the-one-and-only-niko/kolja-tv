# KÖLJA TV-14 — the big screen for Retrotv

Open **https://the-one-and-only-niko.github.io/kolja-tv/** on a computer, then type the code your phone shows
in Retrotv (CAST TO COMPUTER), or scan the phone's QR code.

The page plays the channel straight from the broadcaster. The phone is the remote. When the phone and the
computer can't reach each other on the Wi-Fi, they talk through public Nostr relays; every message is
sealed with a key made from the pairing, so relays only pass along noise. Nothing here is secret: each
browser makes its own key and keeps it in its own storage.

Video player: [hls.js](https://github.com/video-dev/hls.js) (Apache-2.0, see hls.js-LICENSE.txt).
